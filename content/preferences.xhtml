Язык книги — на нём написан читаемый PDF; подсвечиваются только слова этого языка. Язык перевода — на который переводить. Их же можно быстро сменить кнопками в верхней панели читалки. Доступны английский, китайский, немецкий, французский, испанский, португальский и русский — в любую сторону. Онлайн-перевод работает для любой пары; для работы без интернета скачайте офлайн-словарь ниже. Словари не входят в плагин: скачайте только нужные. Один словарь — одно направление (например, «Немецкий → Английский»), для обратного направления нужен отдельный. После скачивания слова переводятся без интернета; словарь хранится в папке данных Zotero и его можно удалить в любой момент. Для английского → русского в словарь входит и база идиом. Нужного направления в списке нет — пока работает только онлайн-перевод.
